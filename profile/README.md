# Transformaiton.com

Welcome. This organization is the public GitHub home for Transformaiton.com, where we share skills, tools, and resources with clients.

We build AI solutions, mentor the people who use them, and implement that work in everyday operations. The focus is practical: solution building, mentoring, and implementation.

These resources are being assembled. Please browse the public repositories on this organization as they are added.

## Skills

Practical skills for AI solution building, mentoring, and implementation will be published here as they are ready to share. Each skill will appear as a repository on this organization. You are welcome to browse them as they are added.

## Tools & Automations

Tools and automations that support the same work will be shared here as well. The collection is being gathered now. A tool will show up as its own repository when it is ready for clients to use.

## Client Resources

Guides and reference material prepared for clients will be added alongside the skills and tools. While that library is being assembled, the website is the place to read about Transformaiton.com and to get in touch.
